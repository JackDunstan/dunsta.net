# dunsta.net

Personal website for Jack Dunstan, hosted at [dunsta.net](https://dunsta.net).

## Overview

A minimal single-page site with a hero photo and a direct link to LinkedIn.

## Structure

```
dunsta.net/
├── index.html              # Home page
├── assets/
│   ├── css/styles.css      # Bundled stylesheet (Bootstrap base + custom)
│   └── images/
│       └── jack-2026.jpg   # Hero photo
├── projects/               # Project sub-pages
├── calendar/               # Calendar page
└── CNAME                   # GitHub Pages custom domain
```

## Deployment

Deployed via GitHub Pages. Pushes to `main` go live automatically at dunsta.net.

## Local development

Open `index.html` directly in a browser — no build step required.
